# ProyectoPrincipal


Proyecto de ejemplo y ejercicios creado para un curso de C# (Udemy). Contiene ejemplos básicos y ejercicios prácticos para aprender sintaxis, estructuras de control, métodos y manejo de arreglos en .NET 8.

## Requisitos
- .NET 8 SDK
- Visual Studio 2022 (o CLI con .NET 8)

## Cómo ejecutar
1. Abrir la carpeta del proyecto en Visual Studio 2022.
2. Seleccionar la configuración __Debug__ o __Release__ según convenga.
3. Compilar con __Build > Build Solution__.
4. Ejecutar con __Start Debugging__ (F5) o __Start Without Debugging__ (Ctrl+F5).

Alternativa por línea de comandos:

dotnet run --project "ProeyctoPrincipal.csproj"

## Estructura principal de archivos
- `Program.cs` — Punto de entrada del proyecto.
- `Conceptos.cs` — Ejemplos y notas sobre conceptos básicos de C#.
- `Sentencia.cs` — Ejemplos de sentencias condicionales.
- `Ciclos.cs` — Ejemplos de bucles (for, while, foreach).
- `Metodos.cs` — Definición y uso de métodos.
- `Arreglos.cs` — Ejemplos con arrays y colecciones.
- `Ejercicio1.cs`, `Ejercicio2.cs`, `Ejercicio3.cs`, `Ejercicio4.cs` — Ejercicios prácticos para aplicar lo aprendido.

## Notas
- El proyecto está dirigido a aprendizaje y práctica, no es una aplicación productiva.
- Para cambios en la versión de .NET editar el fichero del proyecto (.csproj) y ajustar el TargetFramework.
